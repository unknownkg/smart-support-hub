# Результаты проверки Smart Support Hub

Дата: 8 ноября 2026 года. Проверены первая опубликованная версия v1.0.0 и обновлённый сайт с исправлениями v1.1.0. Адрес: [GitHub Pages](https://unknownkg.github.io/smart-support-hub/).

## Автоматические проверки

- v1.0.0: `npm test` — 8 тестов успешно, 0 ошибок.
- v1.1.0: `npm test` — 12 тестов успешно, 0 ошибок.
- `node scripts/check-site.mjs https://unknownkg.github.io/smart-support-hub/` — 5 страниц и 19 локальных ресурсов доступны по HTTP, импорты существуют, пути относительные, MIME JavaScript корректен. Проверены три локальных шрифта через CSS URL.
- Локальный предпросмотр с префиксом `/smart-support-hub/` также прошёл проверку ресурсов.

Основной набор проверяет точные границы SLA 4/8/24/72 часа, +1 мс просрочки, своевременное и позднее решение, отсутствие даты решения, SemVer patch/minor/major, неправильный ввод, KPI и повторное решение. Хранилище проверено на отдельном адаптере памяти: сохранение, повреждение, ошибку записи, неверную структуру и повторяющиеся ID. Пользовательские данные для автоматических тестов не используются.

## Дополнительная браузерная регрессия

- Все пять страниц открыты через Sidebar на **1366, 768 и 390 px в обеих темах: 30 сочетаний**. Документ и формы без горизонтального переполнения; футер помещается по ширине; заголовки видимы при загрузке; Onest загружен. Широкие таблицы имеют собственную прокрутку.
- Обе диаграммы Chart.js реально отрисованы в светлой, тёмной и мобильной версиях; проверены снимками. Данные заявок и приоритетов обновляются после действий.
- Внедрение с готовностью 4/3 отклонено; 1/3 создано, этап изменён на training, выполнена ещё задача. После reload — 2/3 и 67%.
- SemVer для v1.2.1: patch → v1.2.2, minor → v1.3.0, major → v2.0.0. v01.2.3 отклонена. Созданный тестовый релиз v1.3.0 сохранился; калькулятор предложил v1.3.1. Повтор версии отклонён, количество релизов осталось 3.
- Tab проходит пять ссылок мобильного меню и кнопку; Escape закрывает меню и возвращает фокус на кнопку. Outline — 3 px. После смены статуса заявки фокус остаётся на SELECT.
- Светлая и тёмная темы сохраняются после reload. Ошибок и предупреждений JavaScript за проверенную сессию не обнаружено.

## Границы проверки

Активный системный `prefers-reduced-motion: reduce` не проверен: доступная автоматизация изменяет viewport, но не эмулирует media features; фактическое значение было false. CSS отключает переходы при reduce, Chart.js всегда работает без анимации. Ручной шаг: включить уменьшение движения в ОС/DevTools, обновить панель, проверить меню и кнопки.

Другие браузеры, реальные мобильные устройства и экранный диктор не проверялись. Chart.js 4.4.8 требует доступа к CDN jsDelivr; шрифты локальны. Источники и лицензии — в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

Отзывы одногруппника пока не получены. Технические Issues и их закрытие не подтверждают этот отдельный пункт методички.
