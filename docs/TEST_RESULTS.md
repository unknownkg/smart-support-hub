# Проверки перед первой публикацией v1.0.0

Дата: 8 ноября 2026 года. Проверен локальный проект. Публичная публикация GitHub Pages и тег v1.0.0 ещё не подтверждены.

## Автоматические проверки

`node --test tests/*.test.js`: **8 тестов успешно, 0 ошибок**.

Проверяются SLA для critical/high/medium/low с порогами 4/8/24/72 часа, точный дедлайн, позднее решение, отсутствие даты решения; SemVer patch/minor/major; валидация; KPI; повторное решение; сохранение, повреждённые данные и отказ записи. Проверки слоя хранения используют отдельный адаптер памяти, не пользовательские записи.

`node scripts/check-site.mjs http://127.0.0.1:8083/smart-support-hub/`: **5 страниц и 19 локальных ресурсов доступны**, импорты существуют. Проверены JavaScript MIME-типы, относительные пути и три файла шрифта, подключённые через CSS.

Синтаксис JavaScript и локального сервера проверен Node.js. Установка npm-зависимостей для тестов и сайта не требуется.

## Локальная имитация GitHub Pages

Команда `node scripts/serve-preview.mjs --port 8083 --prefix /smart-support-hub/` раздаёт текущий проект под тем же префиксом, который предполагается для Pages. Это проверка путей, а не публикация.

Через Sidebar открыты все пять страниц. Ссылки сохраняют префикс `/smart-support-hub/`; CSS, JavaScript и локальный Onest загружаются. На панели реально отрисованы оба графика Chart.js с CDN. Консоль без ошибок и предупреждений.

## Версии и зависимости

Перед первой фиксацией футер и Sidebar обновлены до «v1.0.0». Это версия приложения. Версия обслуживаемого демонстрационного продукта в исходных данных остаётся v1.2.1; тестовые записи менялись только в отдельном наборе.

Onest локален и поставляется с OFL. Chart.js 4.4.8 загружается с CDN jsDelivr и требует интернета. Полная автономность диаграмм не заявляется. Сведения и лицензии — в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

## Что ещё не проверено

- Реальный публичный URL GitHub Pages, состояние его сборки и история GitHub после push.
- Активный системный режим уменьшения движения: правила CSS есть, но инструмент браузерной проверки не эмулирует media features. Графики всегда обновляются без анимации. Ручной шаг: включить reduced motion в ОС или DevTools, обновить панель и проверить кнопки и меню.
- Другие браузеры, реальные мобильные устройства и экранный диктор.
- Реальная обратная связь после первой публикации, два Issues и второй релиз.
