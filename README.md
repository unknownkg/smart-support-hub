# Smart Support Hub

Учебная платформа внедрения и сопровождения программного продукта на HTML5, CSS3, JavaScript и Chart.js.

**Текущая версия приложения: v1.1.0.** Демонстрационная версия обслуживаемого продукта `v1.2.1` в KPI и таблице релизов — отдельные учебные данные.

## Локальный запуск

Откройте терминал в корне проекта. Для встроенной статической раздачи нужен Node.js 22 или новее; установка npm-пакетов не требуется.

```powershell
npm start
```

Откройте [панель управления](http://127.0.0.1:8080/). Для остановки нажмите Ctrl+C. Запасной вариант — `python -m http.server 8080 --bind 127.0.0.1` или VS Code Live Server. Через `file://` приложение не запускается: JavaScript-модулям нужен HTTP.

## Возможности

- Пять страниц: панель, внедрения, инциденты, заявки и релизы.
- Четыре KPI и две диаграммы Chart.js, вычисляемые по текущим данным.
- Добавление внедрений, смена этапа и увеличение готовности.
- Создание инцидентов, приоритет, фильтр, взятие в работу, решение с датой и SLA 4/8/24/72 часа.
- Заявки четырёх видов сопровождения, статусы и целевые версии.
- История релизов продукта и числовой расчёт patch/minor/major.
- localStorage для данных и темы, адаптивный интерфейс Navy, светлая и тёмная темы.

Начальный набор: 3 внедрения, 6 инцидентов, 4 заявки и 2 релиза. Все люди и организации в нём вымышлены. Даты инцидентов создаются относительно первого открытия, затем сохраняются.

## Зависимости

Для самого сайта Node.js, Python и сборка не нужны. Это статические HTML/CSS/JS-файлы; сервер приложения и база данных отсутствуют.

Chart.js **4.4.8** подключён с CDN jsDelivr. Для загрузки диаграмм требуется интернет и доступ к CDN. Если библиотека не загрузилась, приложение показывает сообщение об ошибке; остальные страницы доступны. Полная автономная работа диаграмм без интернета не заявляется.

Шрифт Onest хранится локально в трёх начертаниях, около 271 КБ. Лицензия OFL включена в проект. Внешний Google Fonts не используется. Источники и лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Проверки

```powershell
npm test
node scripts/check-site.mjs
```

Вторая команда выполняется при запущенном сервере на порту 8080. Для проверки путей, как у проекта GitHub Pages:

```powershell
node scripts/serve-preview.mjs --port 8083 --prefix /smart-support-hub/
```

В другом терминале:

```powershell
node scripts/check-site.mjs http://127.0.0.1:8083/smart-support-hub/
```

Сервер отдаёт те же файлы проекта, без отдельной копии приложения. Он доступен только на loopback и не раздаёт служебные каталоги разработки.

Адрес: [Smart Support Hub](https://unknownkg.github.io/smart-support-hub/). Результат проверки публикации фиксируется в протоколе тестирования. ## Ограничения

Данные принадлежат браузеру, профилю и origin. `localhost`, `127.0.0.1` и GitHub Pages имеют разные хранилища; записи не мигрируют автоматически. Очистка данных сайта удаляет записи. Синхронизации между устройствами нет. Перед последовательной записью читается актуальный набор других вкладок. localStorage не даёт атомарных транзакций между вкладками; это не многопользовательский режим.

Режим уменьшения движения реализован в CSS; его проверка при активной системной настройке пока требует ручного участия. Диаграммы обновляются без анимации.
